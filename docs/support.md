## Code source

https://github.com/elias-code-1/payflow

## Comment obtenir de l’aide

- Lire la documentation du projet dans le dépôt GitHub
- Vérifier la configuration locale
- Vérifier le fichier `.env`
- Vérifier l’état du backend Express et le port 3001
- Vérifier le build Vite

## Communauté

Le projet est ouvert à la contribution et à l’amélioration collaborative. PayFlow ne reçoit aucune notification de paiement : le marchand met lui-même à jour chaque statut.
